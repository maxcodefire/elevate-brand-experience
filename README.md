# Elevate Brand Experience

Good. Now implement the approved direction.

Build the website according to the master specification.

Do not create a generic AI-generated landing page.

Do not simplify the design into cards and gradients.

Prioritize:

Brand perception

Hero quality

Typography

Visual storytelling

Service presentation

Case studies

Responsive UX

Motion quality

Performance

Conversion

After implementation, inspect the result visually at desktop, tablet and mobile sizes.

Then perform a self-review as a Creative Director, Senior UX Designer, CRO specialist and CTO.

Fix the weakest areas before considering the task complete.

Do not stop at "the website works."

The website must feel finished, intentional and premium.

Phase 1 = Audit → Strategy → Art Direction
Phase 2 = Build
Phase 3 = Critique → Refine.
